# 悦子吃什么：实施计划

## 执行原则

- 按可独立验收的阶段推进，每个阶段先写关键测试，再实现功能。
- 第一阶段只建立可运行骨架、数据库和认证，不提前实现菜单业务。
- 每个阶段结束时执行类型检查、单元测试、构建和必要的浏览器验证。
- 所有持久化数据通过挂载目录保存；密钥和初始密码只来自环境变量。

## 阶段 1：基础骨架、数据库与认证

### 目标

完成 Nuxt 全栈项目、薄荷便当社基础主题、SQLite/Drizzle、角色与管理员初始化、登录/退出、用户会话、角色守卫和基础 Docker 环境。

### 主要文件

- `package.json`、`nuxt.config.ts`、`tsconfig.json`
- `app/app.vue`、`app/assets/css/main.css`
- `app/pages/login.vue`、`app/pages/index.vue`、`app/pages/admin/index.vue`
- `app/middleware/auth.ts`、`app/middleware/admin.ts`
- `server/database/schema.ts`、`server/database/client.ts`、`server/database/migrate.ts`
- `server/services/auth.ts`、`server/services/bootstrap.ts`
- `server/api/auth/login.post.ts`、`logout.post.ts`、`session.get.ts`
- `server/api/admin/users/*`
- `server/middleware/session.ts`
- `test/unit/*`、`test/api/*`
- `.env.example`、`Dockerfile`、`compose.yaml`

### 验证

- 首次启动创建两种角色和一个环境变量指定的管理员。
- 密码哈希不以明文落库。
- 未登录访问受保护页面会跳转登录页。
- 普通用户无法访问管理 API。
- 登录、退出、会话恢复测试通过。
- `pnpm test`、`pnpm typecheck`、`pnpm build` 通过。

## 阶段 2：分类、食材、菜品与食谱

### 目标

完成 PC 资料管理和移动端菜单浏览。

### 工作项

1. 分类表、菜品表、多对多关联及约束。
2. 食材、菜品食材和食谱步骤。
3. 图片上传与安全校验。
4. 管理端分类树、菜品编辑、食材和食谱编辑。
5. 移动端一级/二级分类、搜索、菜品卡片和详情。

### 验证

- 第三级分类创建失败。
- 同一菜品可绑定多个分类。
- 关联中的分类不可删除。
- 草稿或下架菜品不出现在普通用户菜单。
- 图片类型和大小限制生效。
- 管理 CRUD、移动端浏览和构建测试通过。

## 阶段 3：多菜点单与订单处理

### 目标

完成购物车、订单状态机、食材汇总、管理员处理和应用内通知。

### 工作项

1. 订单、订单项、状态历史和通知表。
2. 移动端多菜购物车、日期、餐次和备注。
3. 管理端订单详情、当前食谱和合并食材清单。
4. 接受、准备、完成、拒绝和用户取消状态操作。
5. 应用内通知列表和未读数量。

### 验证

- 一张订单包含多道菜及菜名快照。
- 同食材同单位正确合并，不同单位分开展示。
- 非法状态跳转被服务端拒绝。
- 用户只能查看和取消自己的待确认订单。
- 订单事务和通知记录保持一致。

## 阶段 4：未上架菜品需求

### 目标

完成新菜需求提交、研究、拒绝、转菜品草稿和发布闭环。

### 验证

- 用户只能查看自己的需求。
- 接受需求后只创建一个关联菜品草稿。
- 草稿发布后需求自动标记为已发布。
- 状态历史和应用内通知完整。

## 阶段 5：PWA、Web Push 与生产部署

### 目标

完成主屏幕安装、推送通知、HTTPS、备份和真机验收。

### 工作项

1. Manifest、图标、Service Worker、更新提示。
2. Push 订阅、VAPID 配置、发送与失效订阅处理。
3. Caddy 配置、生产 Compose、健康检查。
4. SQLite 与图片目录备份/恢复脚本。
5. 两台 iPhone 安装和推送验收清单。

### 验证

- 域名 HTTPS 下可添加到主屏幕并独立运行。
- 管理员和用户分别收到设计规定的通知。
- 推送失败不影响订单或需求提交。
- 容器重启不丢数据，备份可恢复。

## 当前执行范围

本轮从阶段 1 开始。阶段 1 验证通过后再进入阶段 2，不在骨架阶段提前引入菜单业务文件。
