# 全局主题切换实施计划

## 目标

在不复制业务页面的前提下，增加数据库持久化的全局主题设置，并实现“蜜桃小厨房”与“薄荷便当社”的管理端切换。

## 实施步骤

1. 新增系统设置表和默认主题初始化，生成 Drizzle 迁移。
2. 新增主题读取服务、公共读取接口和管理员更新接口，覆盖权限与非法值测试。
3. 新增应用级主题状态，在 SSR 和客户端读取主题并设置 `html[data-theme]`。
4. 将现有样式改为语义变量，保持薄荷主题现状并补充蜜桃主题变量与主题化文案。
5. 在管理侧边栏增加“外观设置”，实现两张预览卡和即时切换反馈。
6. 执行单元测试、类型检查、生产构建，以及移动端和 PC 端浏览器验收。

## 完成标准

- 管理员切换后当前页面立即生效。
- 其他设备刷新后读取同一数据库主题。
- 登录页和全部业务页面统一跟随主题。
- 两种主题可往返切换且非法值被拒绝。
- 测试、类型检查和生产构建通过。
